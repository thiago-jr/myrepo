## 1. Implemente en un notebook de Google Colab los siguientes algoritmos para el ordenamiento de arreglos:

- Ordenamiento por inserción
- Ordenamiento por burbuja
- Ordenamiento por selección
- Ordenamiento por mezcla (Merge Sort)
- Quicksort

## 2. Genere un archivo de texto plano con un listado de quinientos mil números enteros. De este vector tome muestras de las siguientes dimensiones:

- Quinientos números
- Mil números
- Diez mil números
- Treinta mil números
- Cincuenta mil números
- Cien mil números
- Doscientos mil números
- Trescientos mil números
- Cuatrocientos mil números
- Quinientos mil números

Registre en una tabla el tiempo de ejecución de cada algoritmo para ordenar cada muestra. Repita el procedimiento cinco veces para cada combinación de algoritmo y muestra. Promedie los cinco tiempos para cada combinación de algoritmo y muestra.

## 3. Grafique los tiempos promedio para cada combinación muestra-algoritmo de modo tal que se puedan comparar los tiempos de ejecución de los algoritmos. Identifique la función que mejor se ajusta a los datos de cada algoritmo. ¿Qué información sobre los algoritmos le da la gráfica?
